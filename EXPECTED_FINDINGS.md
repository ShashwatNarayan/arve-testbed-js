- **SAST-02** — Bare exec() (imported from node:child_process) with a template literal holding req.query.format. Lives in .ts. CodeQL reports 3 queries on this line: the request source, plus two for the outDir/src paths, which derive from process.env.DOCVAULT_STORAGE.
- **SAST-03** — res.send of a template literal holding req.query.highlight. Lives in .ts.
- **SAST-04** — innerHTML from a fetch() response in the static .js page. CodeQL does not treat a fetch response as a DOM-XSS source, so this is Semgrep-only.
- **SAST-05** — eval of the settings bundle request body. Lives in .ts.
- **SAST-06** — fs.readFile(path.join(dir, name)) with name from req.query. ARVE has no JS path-traversal rule, so this is CodeQL-only.
